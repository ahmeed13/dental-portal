# بوابة الحساب الإلكتروني | كلية طب الأسنان (تطبيق PWA متكامل)

حزمة تطبيق ويب تقدمي (**Progressive Web App - PWA**) جاهزة للنشر والتثبيت على هواتف **Android** و **iPhone (iOS)** مع الحفاظ الكامل على نفس التصميم والهوية البصرية للبوابة، ودعم العمل بدون إنترنت (**Offline Mode**).

---

## محتويات الحزمة

```text
dental-portal-pwa/
├── index.html          # الواجهة الرئيسية للتطبيق مربوطة بالـ Manifest والـ Service Worker
├── manifest.json       # ملف تعريف التطبيق (الاسم، الألوان، اتجاه RTL، وضع Standalone، والأيقونات)
├── sw.js               # Service Worker لتخزين ملفات التطبيق والعمل بدون إنترنت (Offline)
├── assets/
│   ├── styles.css      # تنسيقات Tailwind المُترجمة مسبقاً (بدون الحاجة لـ CDN خارجي)
│   └── fonts/          # خطوط Tajawal و Roboto Mono بصيغة woff2 محلياً لسرعة فائقة وعمل أوفلاين
└── icons/              # أيقونات التطبيق بجميع المقاسات القياسية + Maskable للأندرويد + Apple Touch للآيفون
```

---

## طريقة رفع ونشر التطبيق (خلال دقيقة واحدة مجاناً)

> **ملاحظة مهمة:** يشترط متصفح Chrome و Safari أن يعمل الرابط عبر بروتوكول آمن **`https://`** لتفعيل ميزة تثبيت التطبيق والـ Service Worker.

### الطريقة الأسهل (بدون برمجة): Netlify Drop
1. افتح موقع [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب مجلد `dental-portal-pwa` (أو ملف `dental-portal-pwa.zip`) وأفلته في الصفحة.
3. ستحصل فوراً على رابط `https://...` جاهز لإرساله للطلبة وتثبيته كتطبيق على الهواتف.

### أو عبر GitHub Pages / استضافة الكلية
- ارفع جميع محتويات مجلد `dental-portal-pwa` إلى المستودع أو مجلد فرعي في موقع الكلية الرسمي (جميع المسارات داخل التطبيق نسبية `./` فتعمل سواء على النطاق الرئيسي أو داخل مجلد فرعي مثل `https://college.edu.iq/portal/`).

## طريقة التثبيت لدى الطلبة

- **هواتف الأندرويد (Chrome / Samsung Internet / Edge):**
  يظهر شريط علوي تلقائياً داخل الموقع: **«📲 قم بتثبيت التطبيق على هاتفك للوصول السريع — [تثبيت الآن]»**، وبمجرد الضغط عليه يُثبَّت التطبيق بأيقونته الرسمية في قائمة التطبيقات والشاشة الرئيسية ويعمل بملء الشاشة تماماً كتطبيق أصلي.
- **هواتف الآيفون والآيباد (Safari):**
  عند الضغط على زر **«تثبيت الآن»** تظهر للطالب نافذة إرشادية مبسطة بخطوتين (مشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**)، ليظهر التطبيق بأيقونته الكاملة وبوضع ملء الشاشة بدون شريط المتصفح.

---

## العمل بدون إنترنت (Offline)
- عند فتح التطبيق لأول مرة، يقوم `sw.js` بحفظ جميع ملفات الواجهة والخطوط والأيقونات، كما يقوم التطبيق بحفظ قاعدة بيانات الطلبة محلياً.
- في المرات القادمة يفتح التطبيق فوراً حتى في حال انقطاع الإنترنت تماماً، ويحدّث قائمة الطلبة تلقائياً في الخلفية عند توفر الاتصال.
